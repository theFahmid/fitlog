# FitLog
FitLog is a responsive NextJS-based webapp, which helps users to browse workout routines, and log their daily exercises.

**Live Link:** https://fitlog-alpha-nine.vercel.app/

## Tech Stack
**Language:** HTML, CSS, TypeScript  
**Frontend:** React + NextJS + Tailwind CSS  
**Hosting:** Vercel  
**Library:** React-Toastify

## Installations
### Clone the repository
```bash
git clone https://github.com/theFahmid/fitlog
```
### Install Dependencies
```bash
cd DevStack && npm install
```
### Development
```bash
npm run dev
```
### Production Build
```bash
npm run build && npm run serve
```

## Features
- Browse different workouts with instructions
- Fully Responsive Webapp
- Toast Notifications for user actions
- Add-to-log functionality
- LocalStorage Persistence
